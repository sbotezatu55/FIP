05 / Inputs

Data Sources

FIP is designed to be data-source independent. The initial implementation uses OpenSky flight data to develop and validate the ingestion and reconstruction pipeline. The architecture allows additional sources to be introduced through dedicated adapters while preserving the same internal flight model.

CURRENT

OpenSky

Flight telemetry used for development, integration testing, and reconstruction.

FUTURE / EXPLORATORY
  • Additional ADS-B sources
  • Airport and runway data
  • Navigation data
  • Weather data
